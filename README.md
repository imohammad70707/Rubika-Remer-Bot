# 🇬🇧 English

## 📌 About

**Rubika Remer Bot** is a Rubika group management bot designed to monitor new members and automatically apply predefined moderation rules.

The bot runs directly on a **Rubika bot account** and can operate as a group administrator. When a new member joins, the bot checks their status and applies the configured moderation action when necessary.

## ✨ Features

* 🤖 Runs on a Rubika bot account
* 👑 Designed for group administrator usage
* 👥 Monitors new members
* 🔍 Detects group administrators
* 🛡️ Helps prevent unauthorized members from remaining in the group
* ⏱️ Supports automatic removal after a configured delay
* 📡 Receives and processes group events
* 🔑 Uses a Bot Token for authentication
* ⚙️ Built with Bot API and **MAXRubika 1.10.0**

## ⚙️ How It Works

1. The bot connects to Rubika using a Bot Token.
2. It operates in a group where it has the required administrative permissions.
3. The bot monitors incoming group events.
4. When a new member is detected, their status is checked.
5. Administrators are recognized and handled accordingly.
6. Non-administrative members are processed according to the configured rules.
7. If required, the bot automatically removes the member after the specified delay.

## 🔐 Authentication

The bot requires a **Rubika Bot Token** to connect and operate.

> ⚠️ Never publish your Bot Token in a public GitHub repository.

## 🛠️ Technology

* 🐍 Python
* 🤖 Rubika Bot API
* 📦 MAXRubika `1.10.0`

## 🎯 Use Cases

This project can be useful for:

* Group moderation
* Automatic member management
* New-member monitoring
* Learning Rubika Bot API development
* Building custom group-management systems

## ⚠️ Important Note

The bot should only be used in groups where you have permission to manage members.

Make sure the bot has the appropriate administrative permissions required for its configured moderation actions.
